# 👑 Cunha Life v2.0

O **Cunha Life** é um clone satírico e baseado em texto do famoso jogo *BitLife*, totalmente adaptado à cultura e quotidiano de Portugal. O jogo corre inteiramente no terminal e possui renderização dinâmica de rostos ASCII com base no estado e idade do teu avatar.
## 🛠️ Funcionalidades
- **Rostos Dinâmicos:** Avatares em ASCII que reagem visualmente à tua idade, género e nível de saúde.
- **Ciclo de Vida Completo:** Lida com carreiras, relacionamentos amorosos, gestão financeira e até com deduções fiscais de IRS.
- **Rotas de Carreiras:** Escolhe o teu rumo entre Fama (TikToker, Ator), Desporto (Futebolista), Intelectual (Médico, Engenheiro de IT) ou foca-te na influência política através da **Cunha** (Deputado, Administrador Público).
- **Mecânica Criminal:** Executa pequenos furtos ou entra em esquemas de colarinho branco, arriscando penas efetivas de prisão.
## 🚀 Como Jogar
1. Garante que tens o Python 3 instalado no teu computador.
2. Descarrega o ficheiro `main.py`.
3. Executa o seguinte comando no teu terminal:
   ```bash
   python main.py
   ```
